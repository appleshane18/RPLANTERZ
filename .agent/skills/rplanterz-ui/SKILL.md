# Goal
Whenever generating UI components, apply a minimalist, highly organized aesthetic suitable for a financial and inventory management system.

# Design Rules
1. **Layout & Whitespace:** Prioritize ample whitespace. Dashboards and data tables must be clean, uncluttered, and highly readable.
2. **Containers:** Use subtle drop shadows for cards and form containers to create depth without visual noise.
3. **Colors:** Stick to a professional, cohesive color palette (e.g., crisp white backgrounds, subtle gray borders, and clear accent colors for primary actions like "Save" or "Checkout").
4. **Typography:** Keep fonts legible, especially for numerical financial data and inventory counts. Align numbers to the right in tables.
5. **Execution:** Apply these CSS/styling rules automatically without asking for confirmation.
